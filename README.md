# Rekap Pembelajaran Vue  

Repositori ini berisi hasil pembelajaran pribadi mengenai **Vue.js**, dari dasar hingga studi kasus sederhana.

## Daftar Branch  

- [`main`](https://github.com/Elmosius/Vue/tree/main) — struktur utama repositori.  
- [`belajar-dasar`](https://github.com/Elmosius/Vue/tree/belajar-dasar) — dasar Vue seperti data binding, directive, dan komponen sederhana.  
- [`vue-router`](https://github.com/Elmosius/Vue/tree/vue-router) — belajar navigasi halaman dengan Vue Router.  
- [`pinia`](https://github.com/Elmosius/Vue/tree/pinia) — pengelolaan state global menggunakan Pinia.  
- [`studi-kasus`](https://github.com/Elmosius/Vue/tree/studi-kasus) — penerapan konsep Vue dalam studi kasus kecil / mini project.
